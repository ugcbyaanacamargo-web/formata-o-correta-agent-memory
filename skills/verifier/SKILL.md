# Verifier

## Antes de concluir

1. Declarar qual resultado comprovaria que o problema foi resolvido.
2. Executar ou obter essa verificação.
3. Ler o resultado real.
4. Comparar com o resultado esperado.
5. Verificar efeitos colaterais relevantes.
6. Registrar em `tasks/verification.md`.

## Se falhar

A tarefa continua aberta.

Registrar:
- o que foi testado;
- resultado;
- o que essa falha elimina ou sugere;
- próxima ação.

## Se passar

Fazer uma última verificação coerente com o risco da tarefa antes de concluir.

Nunca substituir evidência por frases como:
- "deve estar resolvido";
- "provavelmente funcionou";
- "parece correto".
