# Memory Manager

## Objetivo

Transformar trabalho realizado em memória reutilizável, sem despejar transcrições nem duplicar informação.

## Ao iniciar uma tarefa complexa

1. Ler `MEMORY_INDEX.md`.
2. Ler `memory/active_context.md`.
3. Ler `tasks/plan.md`.
4. Identificar quais arquivos de memória são relevantes.
5. Recuperar apenas o necessário para orientar o plano atual.

## Durante a tarefa

Registrar imediatamente quando ocorrer:
- descoberta que muda o rumo;
- decisão importante;
- tentativa que falhou de forma informativa;
- nova relação entre componentes;
- fonte decisiva;
- mudança de estado do projeto.

## Ao encerrar

1. Atualizar `memory/active_context.md`.
2. Consolidar aprendizados em `memory/lessons.md`.
3. Atualizar `memory/system_model.md` e `research/knowledge_graph.md` se relações mudaram.
4. Atualizar `tasks/progress.md`.
5. Garantir que `MEMORY_INDEX.md` continue apontando para toda memória importante.

## Regra de qualidade

Memória boa é:
- curta o suficiente para ser recuperada;
- específica o suficiente para orientar ação;
- ligada a evidência;
- conectada a outras partes do conhecimento;
- reutilizável no futuro.
